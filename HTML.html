HTML

  • HTML stands for HyperText Markup Language.
  • It is the standard markup language used to create web pages.
  • Invented by: Tim Berners-Lee.
  • First introduced: 1991.
  • HTML defines the structure and content of a webpage.
  • It uses tags to create elements such as headings, paragraphs, images, links, tables, and forms.
  • HTML documents are saved with the .html extension.
  • Web browsers interpret HTML and display web pages.
  • HTML works with CSS for styling and JavaScript for adding interactivity.
  • HTML5 is the latest major version and includes support for multimedia, semantic elements, and modern web features.
  • HTML is platform-independent and easy to learn.
  • HTML is the foundation of all websites.
